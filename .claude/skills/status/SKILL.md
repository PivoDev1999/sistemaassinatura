1. Leia `docs/ROADMAP.md`, `git log --oneline -15` e `git status`.
2. Confira no código se os itens marcados `[x]` existem de fato. Se houver testes, rode só os dos apps já criados.
3. Responda em português, em no máximo 15 linhas:
   - Fase atual e % concluída
   - Itens marcados que **não** batem com o código (se houver)
   - Trabalho não commitado (se houver)
   - **Próximo item** do ROADMAP e o comando sugerido (ex.: `/nova-feature ...`)
4. Não implemente nada.
